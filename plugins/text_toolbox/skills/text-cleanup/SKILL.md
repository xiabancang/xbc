# 文本清洗与统计

把一段杂乱的文本整理成干净、无重复的结果，并给出统计。

## 步骤

1. **先看当前配置**：调用 `text_defaults`（无参数，只读）。
   确认 `strip_blank_lines` 与 `max_lines` 是否是用户期望的。
   如果不是，**告诉用户去配置里改**，不要自己改配置文件。

2. **统计**：调用 `text_stats`，参数 `text` 传原文。
   返回 `chars` / `lines` / `words` / `blank_lines` / `longest_line`。

3. **去重**：调用 `text_dedupe`，参数 `text` 传原文。
   返回 `text`（去重后的文本）、`kept`（保留行数）、`removed`（移除行数）。

4. **导出**（仅当用户明确要求保存时）：调用 `text_export`，参数 `text` 传**去重后的文本**，
   `filename` 可选。
   - 这是 `write` 风险工具，**需要用户授权**。被内核拒绝时不要重试，直接请用户确认。
   - 返回值里的 `file` 是写入路径，`bytes` 是大小。

## 判断规则

- 如果 `removed` 是 0，说明原文没有重复行 —— 如实告诉用户，不要编造"已去重很多"。
- 如果 `blank_lines` 很多而 `strip_blank_lines` 是 `true`，说明导出时会删除这些空行，
  这个差异要**主动提醒**用户。
- 不要臆测文本含义。这个技能只做机械处理。
