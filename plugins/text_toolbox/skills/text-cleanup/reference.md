# 文本清洗参考

## 什么算"重复行"

按**整行完全相同**判定，比较前不做任何归一化：

- `"abc"` 与 `"abc "`（尾随空格）**算不同**
- `"abc"` 与 `"ABC"` **算不同**
- 空行与空行**算相同**（所以多个连续空行会被压成一行）

如果需要更宽松的去重，先告诉用户把文本规范化，**不要**擅自改动原文。

## 配置项说明

| 配置 | 默认 | 作用 |
|---|---|---|
| `strip_blank_lines` | `true` | 导出时删除空行 |
| `max_lines` | `1000` | 导出时最多保留多少行 |

两项目前只影响 `text_export`（导出），**不影响** `text_stats` 与 `text_dedupe`（它们对原文操作）。
这个差异要主动告诉用户，否则用户会以为统计结果和导出结果一致。

## 常见误用

- 把 `text_stats` 的结果当成"清洗后"的结果 —— 它统计的是**原文**。
- 对超大文本直接调用工具。当前没有分块处理，超过几万行应先提醒用户。
